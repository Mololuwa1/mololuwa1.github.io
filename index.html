Ventures

Three products I started myself. On each one I've done the product, the engineering, the pricing and the selling.

Heliotelligence

In development

A digital twin for solar farms. It models what every string of panels should produce, compares that with what it actually produces, and flags the ones falling short, so a fault is found from a dashboard rather than a site visit. The current build models the pilot site: 49,824 modules, 2,076 strings and 66 inverters.

I built the technical stack: a physics engine on pvlib and pvanalytics, a FastAPI backend on Google Cloud with more than 299 automated tests, and a React front end with a 3D model of the site that colours each group of panels by status. I also built a 36-month financial model.

Running a pilot at Bracon Ash, a 28.5 MWp solar farm, and I've spoken to 10+ asset owners and O&M firms across the UK and US.

AI

How I use it at work, in my own products, and day to day.

Automated client reporting at Barclays

I'm leading a build with our Data Science team that uses several AI agents to produce client insight reports. Each report used to take about 20 hours of manual Tableau work and writing. The system works in four stages:

  1. Pull the client's transaction and benchmark data.
  2. Find the trends and changes worth reporting.
  3. Draft the charts and written commentary.
  4. Check the output, automatically and by an analyst, before it goes to the client.
